# Riverside: Current Synthetic Case

The maintained case describes referral scheduling across a fictional hospital and clinic network.
The current evidence contains 1,484 synthetic referrals with order dates from October 2025 through March 2026.
The generator changes pathway selection after January 1, 2026 and includes authorization, completeness, service-line, booking, attendance, and network-outcome variation.
These are instructional model assumptions, not empirical estimates of a real hospital.

The migration preserves this evidence exactly.
Larger volumes, event histories, and revised mechanisms remain future work.
All generation assumptions remain inspectable in model/referrals.py.
